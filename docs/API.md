# Минимальный HTTP API

Адрес по умолчанию: `http://127.0.0.1:8765`.

| Запрос | Назначение |
|---|---|
| `GET /api/health` | Версия и доступность сервиса |
| `GET /api/state` | Источники и состояние наблюдения |
| `POST /api/hosts` | Регистрация числового источника |
| `POST /api/hosts/{id}/observations` | Передача наблюдений |
| `GET /api/logs` | Состояние чтения журналов |

Регистрация источника, JSON:

```json
{"id":"example","name":"Пример","features":["cpu","memory","requests"]}
```

Наблюдение для зарегистрированного источника:

```json
{"observations":[{"timestamp":1,"values":{"cpu":12,"memory":41,"requests":8}}]}
```

Время наблюдений должно возрастать. Состав показателей постоянен в пределах
одного источника. Неверные данные отклоняются до сохранения.
