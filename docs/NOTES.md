# Примечания к проекту

## Подготовка локальной копии

Исходники, тесты, веб-интерфейс и настройки скопированы без изменения
алгоритмов. Убраны накопленные базы, рабочие логи, временные файлы,
история локальных разборов и служебные отчёты. Добавлены README и правила Git.

## Исследовательские модули и проверки

В пакете сохранены модули экспериментальных сравнений и их конфигурации.
Часть проверок требует внешнего `stage2_calibration` или исходных сохранённых
серий, которых нет в приложенном архиве. Эти данные не восстанавливались.
Полное воспроизведение исследовательских результатов не заявляется.

Тесты, работающие с файлами, используют каталог `work/` в корне проекта.
Он предусмотрен в структуре, результаты тестов исключены из Git.
Сетевым тестам требуется доступ к локальным HTTP-соединениям.

`test_app.py` — учебное приложение для демонстрационных сценариев;
это рабочая часть сервиса, несмотря на префикс `test_`.

IPCA/SVD реализован через NumPy в `_reference_models.py`.
Поддерживаются только заданные профили логов. Для удалённого развёртывания
потребуются отдельные изменения; текущий HTTP-сервер привязан к loopback.
